LA MYSTIQUE — SITE PRONTO PARA HOSPEDAGEM
=============================================

IDENTIDADE APLICADA
- Noite Profunda: #0B0B0B
- Ameixa Mística: #2E0F2E
- Vinho Real: #5B1E2D
- Ouro Antigo: #D4A77F
- Marfim Etéreo: #F6EFE7
- Títulos: Playfair Display
- Textos: Montserrat
- Assinatura: “Clareza para o presente. Caminhos pelo desconhecido.”
- Frase secundária: “Intuição em cada passo.”

ANTES DE PUBLICAR
1. Abra index.html em um editor de texto.
2. Procure por:
   https://instagram.com/SEU_USUARIO
   e substitua pelo seu Instagram real.
3. Procure por:
   https://wa.me/55SEUNUMERO
   e substitua por seu WhatsApp completo, somente números, incluindo 55 + DDD.
4. Quando tiver domínio, acrescente a URL real nas tags Open Graph e crie sitemap.xml.

COMO TESTAR
- Abra index.html no navegador.
- O site funciona como página estática: não exige banco de dados nem servidor especial.

COMO HOSPEDAR
NETLIFY
- Descompacte o ZIP.
- Arraste a pasta LA_MYSTIQUE_SITE para o painel de deploy manual do Netlify.

HOSTINGER / CPANEL
- Envie todo o conteúdo da pasta LA_MYSTIQUE_SITE para public_html.
- Garanta que index.html esteja diretamente dentro de public_html.

GITHUB PAGES
- Crie um repositório.
- Envie index.html, css/, js/ e assets/.
- Ative Pages nas configurações do repositório.

VERCEL
- Importe a pasta ou repositório como projeto estático.

OBSERVAÇÕES
- O site já é responsivo para desktop e celular.
- As imagens estão convertidas para WebP para carregamento mais rápido.
- Os botões de Instagram e WhatsApp são placeholders até você inserir seus dados.
- Não há preços nem agendamento porque a LA MYSTIQUE ainda está em fase de construção.
- A seção de Tarot + Oráculos e as futuras leituras semanais/mensais já estão previstas.
- No futuro, pode ser adicionada agenda, pagamento, formulário de leads e catálogo sem refazer a identidade visual.
